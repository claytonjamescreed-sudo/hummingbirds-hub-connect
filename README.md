# Hummingbirds Partner Hub

can you build a demo of both of these apps using the hummingsbirds brand https://www.hummingbirds.com:
1. Chipp Partner Portal for Hummingbirds:
- Partner application intake and internal review dashboard (approve/decline)
- Embedded partner agreement e-signature and onboarding checklist
- Refer & Earn lead submission with automated HubSpot deal creation and round-robin rep tracking
- 3-gate payout reconciliation ledger (Closed Won -> Topo Brand Invoice Paid -> Ramp Payout)

2. Customer Call Intelligence Hub for Chipp:
- Integration manager for Attention (recorded customer calls) and Granola (strategic meeting notes)
- Call tagging and filtering (#chipp-context)
- AI Call Synthesizer extracting customer pain points, verbatim quotes, objections, and feature requests into structured summaries
- Chipp Knowledge Base sync preview showing live context cards ready for AI agents
